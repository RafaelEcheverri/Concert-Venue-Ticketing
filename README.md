\# Concert Venue Ticketing



This program holds an array representing six different regions of a concert region. Each region has a different cost depending on the quality of the seats. Program is capable of tracking real time occupancy across all six regions. Input validation was implemented and program is capable of displaying information such as the seating chart and total revenue generated / seats sold using included functions using a menu driven interface.





\## Files



\- `ticketing\_v1.java` - Main source code.



\## How to compile





javac ticketing\_v1.java



java ticketing\_v1
