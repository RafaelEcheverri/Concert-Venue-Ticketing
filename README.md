# Concert Venue Ticketing

This program holds an array representing six different regions of a concert venue. Each region has a different cost depending on the quality of the seats.

The program is capable of tracking real-time occupancy across all six regions. Input validation was implemented, and the program can display information such as the seating chart, total revenue generated, and number of seats sold using included functions through a menu-driven interface.

## Files

- `ticketing_v1.java` - Main source code.
